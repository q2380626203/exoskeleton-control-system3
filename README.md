### 6.1 TCP回放协议 (Magic=0xBB66)

回放协议用于从PC端向ESP32发送历史数据进行算法复现和参数调优。

#### 命令类型 (flags高4位)

| 命令 | 值 | 方向 | 说明 |
|------|-----|------|------|
| CMD_DATA | 0x00 | Server→ESP32 | 数据包 |
| CMD_START | 0x10 | Server→ESP32 | 开始回放 |
| CMD_STOP | 0x20 | Server→ESP32 | 停止回放 |
| CMD_PAUSE | 0x30 | Server→ESP32 | 暂停/继续回放 |
| CMD_REQUEST | 0x40 | ESP32→Server | 请求更多数据 |
| CMD_SET_PARAM | 0x50 | Server→ESP32 | 设置参数 |
| CMD_QUERY_PARAM | 0x60 | Server→ESP32 | 查询参数 |
| CMD_PARAM_RESPONSE | 0x70 | ESP32→Server | 参数响应 |

#### 参数ID定义

**电机1参数 (0x00 - 0x1F)**

| 参数ID | 值 | 说明 | 默认值 | 范围 |
|--------|-----|------|--------|------|
| PARAM_M1_TRIGGER_SPEED | 0x00 | 触发速度 | 3.0 | 0.0 ~ 20.0 |
| PARAM_M1_PHASE1_TORQUE | 0x01 | 抬腿力矩 | 0.7 | 0.0 ~ 2.0 |
| PARAM_M1_PHASE1_KD | 0x02 | 抬腿Kd | 0.08 | 0.0 ~ 1.0 |
| PARAM_M1_PHASE2_TORQUE | 0x03 | 压腿力矩 | -1.0 | -2.0 ~ 0.0 |
| PARAM_M1_PHASE2_KD | 0x04 | 压腿Kd | 0.08 | 0.0 ~ 1.0 |
| PARAM_M1_PASSIVE_KD | 0x05 | 被动Kd | 0.05 | 0.0 ~ 1.0 |

**电机2参数 (0x20 - 0x3F)**

| 参数ID | 值 | 说明 | 默认值 | 范围 |
|--------|-----|------|--------|------|
| PARAM_M2_TRIGGER_SPEED | 0x20 | 触发速度 | -3.0 | -20.0 ~ 0.0 |
| PARAM_M2_PHASE1_TORQUE | 0x21 | 抬腿力矩 | -0.7 | -2.0 ~ 0.0 |
| PARAM_M2_PHASE1_KD | 0x22 | 抬腿Kd | 0.08 | 0.0 ~ 1.0 |
| PARAM_M2_PHASE2_TORQUE | 0x23 | 压腿力矩 | 1.0 | 0.0 ~ 2.0 |
| PARAM_M2_PHASE2_KD | 0x24 | 压腿Kd | 0.08 | 0.0 ~ 1.0 |
| PARAM_M2_PASSIVE_KD | 0x25 | 被动Kd | 0.05 | 0.0 ~ 1.0 |

**公共参数 (0x40 - 0x5F)**

| 参数ID | 值 | 说明 | 默认值 | 范围 |
|--------|-----|------|--------|------|
| PARAM_VELOCITY_SCALE | 0x40 | 速度缩放 | 0.8 | 0.1 ~ 2.0 |
| PARAM_VELOCITY_LIMIT | 0x41 | 速度限幅 | 50.0 | 5.0 ~ 100.0 |
| PARAM_PHASE1_TIMEOUT | 0x42 | 抬腿超时(ms) | 750 | 100 ~ 2000 |
| PARAM_PHASE2_TIMEOUT | 0x43 | 压腿超时(ms) | 750 | 100 ~ 2000 |


### 9. 配置参数 (main.cpp)

所有配置参数集中在 `main.cpp` 中，修改后重新编译即可生效。

#### 9.1 功能开关

| 宏定义 | 默认状态 | 说明 |
|--------|----------|------|
| `ENABLE_BT_IMU` | 禁用 | 启用蓝牙IMU连接 |
| `ENABLE_WIFI_WAN_TCP` | 启用 | 启用WiFi外网TCP上传 (云服务器) |
| `ENABLE_WIFI_LAN_TCP` | 禁用 | 启用WiFi局域网TCP上传 (手机热点网关) |
| `ENABLE_SERIAL_4G_TCP` | 启用 | 启用串口0透传4G模块TCP |

注：注释掉对应行即可关闭该功能

#### 9.2 硬件引脚配置

| 模块 | 宏定义 | 默认值 | 说明 |
|------|--------|--------|------|
| 电机驱动 | `UART_PORT_NUM` | UART_NUM_2 | UART端口号 |
| | `UART_TX_PIN` | GPIO12 | UART TX引脚 |
| | `UART_RX_PIN` | GPIO13 | UART RX引脚 |
| | `MAX485_RE_DE_PIN` | GPIO11 | RS485方向控制引脚 |
| | `UART_BAUD_RATE` | 4000000 | 波特率 |
| 4G模块 | `GPIO_4G_RESET` | GPIO10 | 复位引脚 (高电平正常) |
| 语音模块 | `VOICE_UART_NUM` | UART_NUM_1 | UART端口号 |
| | `VOICE_TX_PIN` | GPIO2 | UART TX引脚 |
| | `VOICE_RX_PIN` | GPIO1 | UART RX引脚 |
| | `VOICE_BAUDRATE` | 9600 | 波特率 |
| 按键 | `BUTTON_ASSIST_UP_PIN` | GPIO3 | 助力增加按键 |
| | `BUTTON_POWER_SWITCH_PIN` | GPIO4 | 电源开关 |
| | `BUTTON_ASSIST_DOWN_PIN` | GPIO5 | 助力减少按键 |

注：UART0引脚(GPIO43/44)为系统默认，不可修改，否则会导致透传和烧录异常
