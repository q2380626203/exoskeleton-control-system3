### 6. 数据包格式 (协议v6)

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    tcp_data_packet_t (2608 bytes)                        │
├─────────────────────────────────────────────────────────────────────────┤
│  Offset  │  Size  │  Field        │  Description                        │
├─────────────────────────────────────────────────────────────────────────┤
│  0       │  2     │  magic        │  0xAA55 (帧头)                      │
│  2       │  2     │  device_id    │  设备ID                             │
│  4       │  2     │  version      │  协议版本 (6)                       │
│  6       │  2     │  seq          │  序列号                             │
│  8       │  2     │  count        │  样本数量 (100)                     │
│  10      │  2598  │  samples[100] │  100个采样数据                      │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│                    motor_sample_int_t (26 bytes)                         │
├─────────────────────────────────────────────────────────────────────────┤
│  Offset  │  Size  │  Field        │  Description                        │
├─────────────────────────────────────────────────────────────────────────┤
│  0       │  8     │  timestamp_ms │  北京时间戳 (毫秒)                  │
│  8       │  2     │  channels[0]  │  motor1_pos × 100                   │
│  10      │  2     │  channels[1]  │  motor1_vel × 100                   │
│  12      │  2     │  channels[2]  │  motor1_torque × 100                │
│  14      │  2     │  channels[3]  │  motor2_pos × 100                   │
│  16      │  2     │  channels[4]  │  motor2_vel × 100                   │
│  18      │  2     │  channels[5]  │  motor2_torque × 100                │
│  20      │  2     │  roll_left    │  左腿roll × 100 (0x7FFF=未连接)     │
│  22      │  2     │  roll_right   │  右腿roll × 100 (0x7FFF=未连接)     │
│  24      │  1     │  m1_state     │  电机1状态 (0:静止,1:抬腿,2:压腿)   │
│  25      │  1     │  m2_state     │  电机2状态 (0:静止,1:抬腿,2:压腿)   │
└─────────────────────────────────────────────────────────────────────────┘
```

### 7. 硬件连接

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           ESP32-S3 引脚分配                              │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  UART0 (Console/4G透传)                                                 │
│  ├── TX: 默认引脚 ──────────────────────► 4G模块 RX                     │
│  └── RX: 默认引脚 ◄────────────────────── 4G模块 TX                     │
│                                                                         │
│  UART1 (语音模块)                                                       │
│  ├── TX: GPIO17 ────────────────────────► 语音模块 RX                   │
│  └── RX: GPIO18 ◄──────────────────────── 语音模块 TX                   │
│                                                                         │
│  UART2 (电机RS485)                                                      │
│  ├── TX: GPIO12 ────────────────────────► MAX485 DI                     │
│  ├── RX: GPIO13 ◄──────────────────────── MAX485 RO                     │
│  └── DE/RE: GPIO11 ─────────────────────► MAX485 DE/RE (拉高)           │
│                                                                         │
│  按键 (GPIO)                                                            │
│  ├── GPIO3: 助力增加 (下拉输入)                                         │
│  ├── GPIO4: 电源开关 (下拉输入)                                         │
│  └── GPIO5: 助力减少 (下拉输入)                                         │
│                                                                         │
│  蓝牙 (BLE Central)                                                     │
│  ├── 设备1: 00:0c:bf:16:0a:37 (左腿IMU)                                 │
│  └── 设备2: 00:0c:bf:06:74:4f (右腿IMU)                                 │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 8. 编译和烧录

```bash
# 设置IDF环境
. $IDF_PATH/export.sh

# 配置项目
idf.py menuconfig

# 编译
idf.py build

# 烧录
idf.py -p COM3 flash

# 监控串口输出
idf.py -p COM3 monitor
```

### 9. 功能开关

| 宏定义 | 文件 | 说明 |
|--------|------|------|
| `ENABLE_BT_IMU` | main.cpp | 启用蓝牙IMU连接 |
| `TCP_ENABLE_LAN_UPLOAD` | tcp_data_upload.h | 启用局域网TCP上传 |
| `SERIAL_PASSTHROUGH_ENABLE` | tcp_data_upload.h | 启用串口透传(4G) |

### 10. 速度跟随模式参数

| 参数 | 电机1默认值 | 电机2默认值 | 说明 |
|------|-------------|-------------|------|
| trigger_speed | +3.0 rad/s | -3.0 rad/s | 触发速度阈值 |
| phase1_duration_ms | 300 | 300 | 抬腿阶段持续时间 |
| phase2_duration_ms | 300 | 300 | 压腿阶段持续时间 |
| phase1.torque | +0.7 | -0.7 | 抬腿阶段力矩 |
| phase2.torque | -1.0 | +1.0 | 压腿阶段力矩 |
| velocity_scale | 0.8 | 0.8 | 速度缩放因子 |
