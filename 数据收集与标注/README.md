# 数据收集与标注

本目录包含数据采集、标注、分析和预处理的完整工具链，用于生成AI模型训练数据。

## 工具概览

```
1_串口数据采集.py        → 2_数据自动标注.py → 3.x_标注工具.py → 4_理想曲线提取.py → 5_训练数据生成.py
   (采集原始数据)          (自动打标签)      (手动修正)       (提取理想曲线)      (生成训练集)
```

## 工具详解

### 1. 串口数据采集 (1_串口数据采集.py)

**功能**：从ESP32串口实时采集双腿运动数据

**使用方法**：
```bash
python 1_串口数据采集.py --port COM3 --output 平地数据_原始.csv
```

**参数**：
- `--port, -p`：串口端口（如COM3、/dev/ttyUSB0）
- `--baudrate, -b`：波特率（默认921600）
- `--output, -o`：输出CSV文件名
- `--duration, -d`：采集时长（秒，可选）

**输出格式**：
```csv
timestamp,m1_pos,m1_vel,m1_torque,m2_pos,m2_vel,m2_torque,ch6_max,ch7_max
9,-14.854674,-0.319068,0.0,25.106644,0.196349,0.0,3.992949,3.9755
```

**采集建议**：
- 平地场景：至少5000行数据
- 包含完整的抬腿-压腿周期
- 保持PWM按键稳定

---

### 2. 数据自动标注 (2_数据自动标注.py)

**功能**：基于速度阈值和PWM按键自动标注运动阶段

**使用方法**：
```bash
python 2_数据自动标注.py --input 平地数据_原始.csv --output 平地数据_已标注.csv
```

**参数**：
- `--input, -i`：输入原始CSV文件
- `--output, -o`：输出标注后CSV文件
- `--vel-threshold`：速度阈值（默认0.1）
- `--no-viz`：禁用可视化输出

**标注规则**：
- **静止**（0）：`abs(velocity) < threshold`
- **抬腿**（1）：`velocity > threshold`（速度为正）
- **压腿**（2）：`velocity < -threshold`（速度为负）

**输出文件**：
- `平地数据_已标注.csv` - 添加m1_label、m2_label列
- `平地数据_已标注_可视化.png` - 可视化标注结果
- `平地数据_已标注_报告.txt` - 统计报告

**注意**：
- m2标签已修正反转逻辑（右腿物理反向）
- 自动标注可能存在误差，需用3.x工具手动修正

---

### 3. 交互式标注工具系列

#### 3.2 双腿对比标注工具 (3.2_双腿对比标注工具_pyqtgraph.py)

**功能**：交互式可视化标注和修正工具

**使用方法**：
```bash
python 3.2_双腿对比标注工具_pyqtgraph.py 平地数据_已标注.csv
```

**功能特性**：
- 双腿数据对比显示
- 鼠标框选修改标签
- 实时预览修改结果
- 撤销/重做功能
- 导出修正后数据

**操作指南**：
1. 加载已标注数据
2. 用鼠标框选需要修正的区域
3. 选择正确的标签（静止/抬腿/压腿）
4. 保存修正后的文件

#### 3.3 AI推理数据对比标注工具 (3.3_AI推理数据对比标注工具.py)

**功能**：对比人工标注和AI推理结果，修正差异

**使用方法**：
```bash
python 3.3_AI推理数据对比标注工具.py 平地数据_已推理.csv
```

**用途**：
- 验证AI模型推理结果
- 发现标注错误
- 生成高质量训练数据

---

### 4. 理想曲线提取 (4_理想曲线提取.py)

**功能**：从标注数据中提取理想运动曲线，用于参数调整标签生成

**使用方法**：
```bash
python 4_理想曲线提取.py --input 平地数据_已标注.csv --output ideal_curves.npz
```

**输出**：
- `ideal_curves.npz` - 包含各阶段的理想速度曲线
- 用于后续参数调整标签生成

---

### 5. 训练数据生成 (5_训练数据生成.py)

**功能**：生成双腿联合模型训练数据（滑动窗口 + 标签）

**使用方法**：
```bash
python 5_训练数据生成.py --input 平地数据_已标注.csv --scene 平地 --output 训练数据_平地_双腿.npz
```

**参数**：
- `--input, -i`：输入已标注CSV文件（必需）
- `--scene, -s`：场景名称（平地/爬楼，必需）
- `--window, -w`：滑动窗口大小（默认50）
- `--step`：滑动步长（默认5）
- `--ideal-curve`：理想曲线NPZ文件（可选）
- `--output, -o`：输出NPZ文件名

**输出格式**：
```
训练数据_平地_双腿.npz:
  - X: (N, 50, 2) - [m1_vel, m2_vel] 速度窗口
  - y_m1_phase: (N,) - m1阶段标签
  - y_m2_phase: (N,) - m2阶段标签
  - y_params: (N, 3) - [delta_torque, delta_kd, delta_scale]
```

**数据格式说明**：
- **仅使用速度**：每个时间步包含 `[m1_vel, m2_vel]`
- **窗口大小**：50个采样点（约1秒历史）
- **标签来源**：窗口最后一个点的标签
- **双腿联合**：单个模型预测m1和m2

## 完整工作流程

### 阶段1：数据采集
```bash
# 1. 连接ESP32，运行主程序
idf.py flash monitor

# 2. 采集数据（约10-20分钟）
python 1_串口数据采集.py --port COM3 --output 平地数据_原始.csv
```

### 阶段2：自动标注
```bash
# 3. 自动标注
python 2_数据自动标注.py --input 平地数据_原始.csv --output 平地数据_已标注.csv

# 4. 检查可视化结果
# 查看 平地数据_已标注_可视化.png
```

### 阶段3：手动修正（可选）
```bash
# 5. 交互式修正错误标注
python 3.2_双腿对比标注工具_pyqtgraph.py 平地数据_已标注.csv

# 保存为 平地数据_已修正.csv
```

### 阶段4：生成训练数据
```bash
# 6. 生成训练数据集
python 5_训练数据生成.py \
  --input 平地数据_已修正.csv \
  --scene 平地 \
  --output 训练数据_平地_双腿.npz

# 7. 查看统计报告
# 自动生成 训练数据统计_平地_双腿.txt
```

## 数据质量要求

### 采集要求
- ✅ 数据量：>5000行（约10分钟）
- ✅ 完整周期：包含抬腿-压腿完整循环
- ✅ 标签平衡：三种阶段比例接近 1:1:1
- ✅ 信号质量：无严重噪声或丢包

### 标注要求
- ✅ 标签准确性：>95%
- ✅ 边界清晰：阶段切换点明确
- ✅ 双腿协调：m1和m2标签合理（通常呈镜像）

### 训练数据要求
- ✅ 样本数：>1000个窗口
- ✅ 阶段分布：静止(30-50%), 抬腿(20-30%), 压腿(20-30%)
- ✅ 双腿状态：验证双腿联合状态分布

## 常见问题

### Q1: m2标签反转问题
**A**: 已在2_数据自动标注.py中修正。m2电机物理反向，代码已处理反转逻辑。

### Q2: 自动标注不准确
**A**: 使用3.2工具手动修正，或调整速度阈值参数。

### Q3: 训练数据不平衡
**A**: 采集时确保包含足够的抬腿和压腿动作，避免长时间静止。

### Q4: 窗口大小如何选择
**A**: 默认50（约1秒）适合大多数场景。可根据动作频率调整。
