# 数据收集与标注工具链（完整版）

用于ESP32外骨骼助力系统的数据采集、标注和AI训练数据生成。

**增强功能**：
- ✅ 基于**位置+速度**双重判断的智能标注
- ✅ 明确区分**左腿(m1)**和**右腿(m2)**
- ✅ 交互式可视化工具，支持位置曲线显示
- ✅ 完整的工作流程：采集→标注→修正→提取→训练

---

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

**依赖包**：
- pandas (数据处理)
- numpy (数值计算)
- matplotlib (可视化)
- scipy (插值算法)
- pyserial (串口通信)

### 2. 采集数据（无助力模式）

**重要**：数据采集时必须关闭电机助力输出！

```bash
# 采集平地行走数据（5分钟）
python 1_串口数据采集.py --port COM3 --scene 平地 --duration 300

# 采集爬楼数据（3分钟）
python 1_串口数据采集.py --port COM3 --scene 爬楼 --duration 180
```

**输出示例**：`平地_数据_20250127_143025.csv`

### 3. 自动标注（智能标注左腿和右腿）

```bash
python 2_数据自动标注.py --input 平地_数据_20250127_143025.csv
```

**输出**：
- `平地_数据_20250127_143025_已标注.csv` - 标注数据
- `平地_数据_20250127_143025_已标注_可视化.png` - 可视化图表（双列对比左右腿）
- `平地_数据_20250127_143025_已标注_报告.txt` - 统计报告

**可调参数**：
```bash

python 2_数据自动标注.py --input data.csv --vel-threshold 1.5

# 调整静止位置阈值（默认0.05 rad）
python 2_数据自动标注.py --input data.csv --pos-threshold 0.03

# 调整平滑窗口（默认5）
python 2_数据自动标注.py --input data.csv --smooth 7
```

### 4. 检查和修正标注（可选）

```bash
# 修正左腿标注
python 3_交互式标注修正.py --input 平地_数据_*_已标注.csv --leg 左腿

# 修正右腿标注
python 3_交互式标注修正.py --input 平地_数据_*_已标注.csv --leg 右腿
```

**界面说明**：

- **操作**：选择标签 → 拖动框选区域 → 自动修正
- **撤销/重置**：支持撤销操作和一键重置

### 5. 提取理想曲线

## 🎯 运动阶段定义

### 电机定义
- **m1 = 左腿**
- **m2 = 右腿**

### 阶段定义（基于位置+速度）

| 阶段ID | 名称 | 速度特征 | 位置特征 | 颜色 |
|--------|------|---------|---------|------|
| 0 | 静止 | \|v\| < 2.0 rad/s | \|Δp\| < 0.05 rad | 灰色 |
| 1 | 抬腿 | v > 2.0 & a > 0 | Δp > 0 (上升) | 绿色 |
| 2 | 过渡 | v从峰值下降 | Δp ≈ 0 (平稳) | 橙色 |
| 3 | 压腿 | v < -2.0 & a < 0 | Δp < 0 (下降) | 红色 |

**符号说明**：
- `v`: 速度 (rad/s)
- `a`: 加速度 (速度变化率)
- `Δp`: 位置变化率

## 🔧 参数调整建议

### 自动标注参数

```bash
# 静止速度阈值 (默认2.0)
--vel-threshold 2.0
  ↓ 降低: 更容易判定为静止
  ↑ 提高: 更严格的静止判断

# 静止位置阈值 (默认0.05)
--pos-threshold 0.05
  ↓ 降低: 位置变化更敏感
  ↑ 提高: 允许更大的位置波动

# 平滑窗口 (默认5)
--smooth 5
  ↓ 减小: 更精细的标注
  ↑ 增大: 更平滑，去噪能力强
```

### 训练数据参数

```bash
# 滑动窗口大小 (默认50)
--window 50
  对应 100ms @ 500Hz
  ↑ 增大: 更多上下文，计算量增加

# 滑动窗口步长 (默认5)
--step 5
  对应 10ms 移动
  ↓ 减小: 更多训练样本，数据冗余度高
```

## 💡 使用技巧

### 1. 数据采集注意事项

- ✅ **必须关闭电机助力**（保证数据是纯用户意图）
- ✅ 保持**规律的运动节奏**
- ✅ 覆盖**不同速度**（慢速/正常/快速）
- ✅ 每个场景采集**至少3分钟**
- ✅ 避免中途停顿或异常动作

### 2. 标注检查要点

查看可视化图表时，检查：
- 位置曲线是否平滑？
- 静止阶段速度是否接近0？
- 抬腿/压腿是否与位置变化一致？
- 过渡阶段是否正确标注？

### 3. 常见问题

**Q: 标注有很多误判怎么办？**
- 调整 `--vel-threshold` 和 `--pos-threshold`
- 使用交互式工具手动修正

**Q: 找不到完整周期？**
- 检查是否有完整的 IDLE→LIFTING→TRANSITION→PRESSING→IDLE
- 延长采集时间
- 保持更规律的运动

**Q: 左右腿标注不一致？**
- 分别可视化检查
- 分别修正

**Q: 理想曲线波动太大？**
- 增加采集时间以获得更多周期
- 保持运动节奏一致
